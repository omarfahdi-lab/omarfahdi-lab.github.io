# Omarfahdi Abed · Portfolio

An Ekko-themed portfolio: every menu is one of his abilities and every back button is a real Chronobreak rewind.
Ekko is a 2D skinned puppet cut from concept art and animated in code with WebGL.

**Live:** https://omarfahdi-lab.github.io

Fan project. Ekko, his voice lines, ability icons and login theme, and League of Legends belong to Riot Games;
not endorsed by Riot. Ekko concept art by [Hicham Habchi](https://www.artstation.com/artwork/Wmve4Q).
